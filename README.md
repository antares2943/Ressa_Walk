# レッサーウォーク（Ressa Walk）
オープンデータ活用アプリコンテスト2026応募用の紹介ページです。


**西山公園デジタル周遊アプリ** — 鯖江市のオープンデータで作った、西山公園の“いま”がわかるスマホWebアプリ。

> レッサーパンダと、季節の花に会いに行こう。

鯖江市「オープンデータ活用アプリコンテスト2026」応募作品。
テーマ：**西山公園を福井県を代表する観光地にするアプリ**

---

## 📱 概要

西山公園の看板スター・**レッサーパンダ**を入口に、来園の「計画 → 園内 → 再訪」をひとつのアプリで支えます。花の見頃・混雑の傾向・アクセス・園内の施設（トイレ／AED）まで、表示はすべて**鯖江市のオープンデータ**に基づいています。

## ✨ 主な機能（5画面）

| 画面 | できること |
|---|---|
| **ホーム** | 今日の混みぐあいの目安・季節の花を最初の画面で確認 |
| **花ごよみ** | 公園案内図の上に、春はツツジ（品種・株数）、秋は紅葉スポットを表示。トイレ・AEDの表示切替も |
| **混雑** | 来園者数データから曜日別・天気別の混み具合を可視化し、すいている日を提案。アクセス情報も掲載 |
| **図鑑** | レッサーパンダの紹介、会えた子のスタンプ、みんなのレッサー写真の投稿・いいね |
| **さんぽ** | 来訪者の居住地割合を可視化し、まちなか回遊・PRの検討材料に |

## 🗂 使用したオープンデータ

鯖江市オープンデータカタログ（出典：CC BY）より活用しています。

- 西山公園のツツジ種類・株数 → 花ごよみ（春）
- 西山公園の来園者数〔日別・人流／天気つき〕 → 混雑（曜日別・天気別）
- 西山公園入場者の居住地割合〔市区町村別・人流〕 → さんぽ
- 公共トイレ（福井県鯖江市） → 園内トイレ
- AED（福井県鯖江市） → AED
- 公園案内図 ／ 紅葉マップ（鯖江市） → 地図のベース

※アクセス・所在地は[鯖江市公式サイト（西山公園）](https://www.city.sabae.fukui.jp/kanko/playing/nishiyama.html)、つつじバスの停留所データも参照。

## 🛠 技術構成

- 単一の **HTML／CSS／JavaScript**（フレームワーク不使用）
- 地図：**Leaflet**（同梱）＋ 鯖江市の公園案内図画像
- オープンデータは集計してアプリに**同梱**（起動時の通信なしで即表示・ほぼオフライン動作）
- スマホ向けUI・**ダーク/ライト両対応**
- 記録（スタンプ・いいね・投稿写真）は端末内に保存（localStorage）

## ▶️ 使い方（ローカルで動かす場合）

このリポジトリを clone し、フォルダ内で簡易サーバーを起動してブラウザで開きます。

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000/ を開く
```

> ダブルクリック（file://）でも表示できますが、一部ブラウザでローカル画像の制限が出る場合があります。上記のローカルサーバー、または GitHub Pages 経由での閲覧を推奨します。

## 📁 ディレクトリ構成

```
├── index.html            … アプリ本体
├── lib/                  … Leaflet（地図ライブラリ）
├── reference/            … 公園案内図・紅葉マップ・レッサー写真
└── data/                 … 参照元のオープンデータCSV（集計済みのため任意）
```

## ⚠️ 仮・デモとして扱っている部分

本アプリの初期版では、以下を「仮・デモ」としています（本番運用で拡充する前提）。

- **写真投稿・いいね**：現状は端末内保存のデモ。表示中の写真・いいね数はサンプル。本番は別サーバーで共有する想定。
- **レッサーパンダの個体情報**（名前・生年月日）：現状はイメージ表示。個体データ連携は今後。
- **秋の紅葉スポット**：本数の公開データが無いため、位置のみを均一の印で表示。
- **トイレ・AEDの位置**：名称・数・設備は実データ。地図が案内図イラストのため、位置は案内図に合わせた目安。
